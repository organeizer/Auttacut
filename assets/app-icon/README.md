# Auttacut app icon

A triangle "A", the A of the owner's AuuToSub wordmark, sliced into bands toward the bottom (cut =
ตัด) in the same VHS style: an orange → blue → green gradient, scanlines, red/cyan edge offsets and a
soft glow, on a dark rounded tile.

## Palette

| Colour | Hex |
|---|---|
| Tile | `#0d0d0f` |
| Gradient | `#ff9a4f`, `#b49ab8`, `#4f8be8`, `#4fb1b0`, `#55c97a` |
| Offsets | `#e2405e` (left), `#2fd0d0` (right) |

## Files

`filmcraft.svg` is the canonical artwork (512-unit viewBox, rounded square `rx=112`);
`filmcraft-small.svg` is a copy. Everything else is generated by `packaging/icons.sh` (needs
`resvg`); on Linux, without `iconutil`, `filmcraft.icns` was written with Pillow from the same macOS
grid render. File names keep the upstream `filmcraft` stem so packaging paths stay unchanged.
